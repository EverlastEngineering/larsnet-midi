## Single Source of Truth for Settings

`webui/settings_schema.py` (`SETTINGS_REGISTRY`) is the single source of
truth for all application settings. Adding a `SettingDefinition` there
with a non-empty `cli_flag` and a `yaml_path` is the ONLY place a new
CLI flag, WebUI form field, and YAML persistence key needs to be
declared.

- CLI flags: generated by `webui/cli_builder.py::build_cli_parser()`.
- WebUI form: consumes `/api/settings/schema` (`webui/api/settings.py`).
- YAML persistence: `webui/yaml_config_core.py` writes to the path in
  `SettingDefinition.yaml_path`.
- Per-stem tuning sliders in `webui/static/js/threshold-tuning.js` use
  `STEM_SLIDER_CONFIGS` and `STEM_FEATURE_CHOICES` keyed by stem type.

Do NOT add argparse calls to `stems_to_midi_cli.py` for new flags; add
them to the schema instead. The CLI loads `midiconfig.yaml`, calls
`apply_cli_overrides()`, and passes the merged config to the pipeline.
